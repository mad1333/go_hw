# HW 2

Из корня репозитория:

```sh
go run ./cmd/movies --from=1 --to=20 --workers=10 --timeout=5s
go test -race ./cmd/movies
```

`--from` и `--to` обязательны. По умолчанию `--workers=10`, `--timeout=5s`.
Таймаут задаётся с единицей времени (`5s`, `500ms`).
Фильмы выводятся по мере загрузки; ошибки отдельных фильмов — в stderr.
Ctrl+C отменяет очередь и текущие запросы.

Коды выхода: 0 — диапазон обработан (возможны ошибки отдельных фильмов),
2 — неверные аргументы, 130 — отмена по Ctrl+C.
