# go_hw — ДЗ 1

Решение [Two Sum](https://leetcode.com/problems/two-sum/description/) на Go.
[Задание](https://gist.github.com/vacmannnn/acbdd3da4b68cdeaac2f3c04c579a7bf).

## Запуск

Требуется Go 1.26 или новее. Внешних зависимостей нет.

```sh
go run .
# [0 1]
go test ./...
go vet ./...
```

## Как работает решение

В `seen` хранятся уже просмотренные числа и их индексы. Для каждого
числа `num` ищем дополнение `target - num`. Если оно уже встречалось,
возвращаем два индекса. Текущее число добавляем после поиска, поэтому один
элемент не используется дважды. Дубликаты и отрицательные числа поддерживаются.

Время — O(n) в среднем, дополнительная память — O(n).
По условию существует ровно одна пара. Если пары нет, функция возвращает `nil`.
